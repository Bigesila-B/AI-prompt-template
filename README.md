# AI Prompt Template

面向 AI 助手与 Agent 的图像、视频提示词规范，以及 LoRA 训练与打标参考。

把创作想法交给 AI 之前，先给它一套清楚的写作规则：保留用户要求、选择适合目标模型的表达方式、核对角色与标签，再组织成可以交给生成模型的提示词。本仓库整理了这套工作方式，也收录了 LoRA 数据集准备、参数选择和打标的实用指南。

所有内容以 Markdown 文档提供，可直接阅读，也可以上传、粘贴或引用给支持相应能力的聊天模型与 Agent 使用。

## 提示词规范包含什么

- **按任务选择写法**：区分图像生成、图片修改、视频生成、视频编辑与延长，保留各自需要的信息。
- **自然语言与标签分工**：用自然语言说明主体、动作、构图和关系；根据目标模型需要，使用经过核验的 Danbooru 标签作为补充，或采用 Tag 优先的表达方式。
- **角色与标签核验**：涉及具名 IP 角色时，要求核对角色标签、作品归属和同名消歧；查询失败时明确说明，不冒充已验证。
- **图像编辑约束**：分别写清需要修改和需要保留的部分，避免改变参考图中的关键特征。
- **视频动作与镜头规划**：组织动作过程、时间顺序、运镜、首尾帧、参考素材职责及声音要求。
- **模型专用章节**：收录 MiniMax H3、Seedance 2.0 的写作规则，并为其他自然语言视频模型提供通用写法。
- **输出自检**：检查人物一致性、动作关系、模型语法和用户要求，默认交付最终可复制的提示词。

## 如何使用

### 1. 选择文档

编写图片或视频提示词时，使用 [prompt-v2.5.md](./prompt-v2.5.md)；准备 LoRA 训练时，使用 [训练与打标指南](./LoRA训练全模型参数与打标实战指南.md)。

### 2. 让 AI 读取

可以选择适合当前工具的方式：

- 在支持文件上传的聊天界面中上传文档。
- 将文档内容粘贴到对话或可配置的指令上下文中。
- 在支持本地文件引用的 Agent 中引用对应文件。
- 在 API 工作流中，将相关章节作为上下文传入。

文档较长时，按任务选取相关章节即可。例如，图像编辑读取通用原则与编辑章节；MiniMax H3 视频读取通用视频规范与 H3 专用章节。

### 3. 提供具体需求

尽量说明目标模型、任务类型、主体、动作、场景、参考素材和必须保留的内容。图片或视频参考素材需一并提供给支持读取该素材的工具。

下面是可直接修改的请求示例。

**图片提示词**

```text
请阅读我上传的 prompt-v2.5.md，按图像生成相关规范编写提示词。

目标模型：支持自然语言描述的生图模型。
画面要求：一位原创银发少女坐在雨夜的咖啡馆窗边，
手捧热饮，窗外有霓虹倒影，室内是柔和暖光。
构图：半身侧面，人物与窗外倒影同时入画。
必须保留：银发、深蓝色外套、安静的氛围。
输出：只给最终提示词。
```

**视频提示词**

```text
请阅读我上传的 prompt-v2.5.md，按 MiniMax H3 相关章节编写提示词。

任务：图生视频，我会提供首帧图片。
画面要求：角色先看向窗外，再缓慢转头看向镜头，最后轻轻微笑。
镜头：缓慢推进，保持连续镜头。
必须保留：参考图中的脸、发型、服装和背景布局。
输出：按目标模型对应模式的格式给出最终提示词。
```

**LoRA 训练与打标**

```text
请参考我上传的《LoRA训练全模型参数与打标实战指南.md》，
为下面的数据集制定训练方案。

基础模型：Flux.1-dev。
训练目标：原创人物角色 LoRA。
数据集：32 张图片，包含不同角度、服装和背景。
训练平台：本地训练器，我会补充具体版本和显存情况。

请给出步数、学习率、Rank / Alpha 和打标方式的建议起点，
说明还需要确认的信息，以及如何通过测试判断欠拟合或过拟合。
```

### 4. 根据结果迭代

将生成结果或训练样张反馈给 AI，明确指出需要调整的部分，例如“人物位置不对”“动作太多”“换装后角色不像”，再针对这些问题修改提示词或训练方案。

## LoRA 指南涵盖的内容

指南按模型和训练目标整理参数与打标思路，涉及 SD 1.5、SDXL、Pony、Illustrious / NoobAI、Flux.1、Krea、Z-Image、MOSS-Image、Qwen-Image 等模型系列，内容包括：

- 图片数量、重复次数、训练轮数与总步数的关系。
- 人物、画风和服装等不同训练目标的数据集与参数选择。
- Danbooru 标签与自然语言打标的使用区别。
- 触发词、固定特征和可变特征的描述方式。
- 过拟合、欠拟合的样张对比与排查方法。
- 魔搭社区训练界面的操作参考，以及供浏览器 Agent 使用的流程说明。

## 使用说明

联网能力有助于核对 Danbooru 标签和模型资料；没有联网能力时，仍可参考文档组织自然语言描述，但应标明未核验的信息。

提示词语法、模型能力、训练参数和平台界面会随版本变化，使用时请结合实际模型卡、官方说明与测试结果调整。训练参数可作为起点，生成效果和训练效果需要通过实际样张评估。
